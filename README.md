# Valen Beauty — versão web

Protótipo responsivo em HTML, CSS e JavaScript puro. Abra `index.html` no navegador; não exige instalação.

## Telas e interações
- **Início:** apresentação e navegação para as demais áreas.
- **Recomendações:** busca por produto/marca, filtro de categoria e preço máximo, ordenação e explicação da sugestão.
- **Em alta:** curadoria de marcas brasileiras e temas de beleza.
- **Meu orçamento:** campo numérico, controle deslizante e valores rápidos; a lista de produtos é recalculada conforme o limite.

## Publicar para a apresentação (GitHub Pages)
1. Envie a pasta `site` para o repositório GitHub do grupo.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/site`, depois salve.
5. Aguarde a publicação e compartilhe o endereço indicado pelo GitHub Pages (`https://USUARIO.github.io/REPOSITORIO/`).

## Limites deste protótipo
Produtos, preços e percentuais são **dados demonstrativos**. A aba “Em alta” é uma seleção editorial ilustrativa, não um ranking atualizado em tempo real. O protótipo ainda não consulta lojas, estoque, avaliações ou o backend original. Não afirma equivalência comprovada de qualidade; para isso, é necessário integrar fontes de preço e critérios comparáveis (composição, desempenho e avaliações).
